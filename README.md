# Skypro LMS — Онлайн образовательная система

Бэкенд-часть образовательной платформы (LMS), разработанная на базе **Django 6** и **Django REST Framework (DRF)**.
Система предоставляет API для управления курсами, уроками, платежами, подписками пользователей и ролевыми правами
доступа.

---

## Стек технологий

* **Python:** 3.12+
* **Фреймворк:** Django 6.0
* **API:** Django REST Framework (DRF)
* **База данных:** PostgreSQL
* **Менеджер пакетов и окружений:** `uv`
* **Документация API:** `drf-spectacular` (OpenAPI 3)
* **Интеграции:** `stripe` (Онлайн-платежи)
* **Фильтрация и Тестирование:** `django-filter`, `coverage`

---

## Функционал

### 1. Управление пользователями и профилями (`users`)

* Кастомная модель `User` унаследована от `AbstractBaseUser`, аутентификация по **Email**.
* Дополнительные поля: `phone`, `city`, `avatar`.
* **Ограничения доступа:** Пользователь просматривает и редактирует **только свой собственный профиль** (при попытке
  доступа к чужому возвращается `403 Forbidden`).
* Вывод истории платежей пользователя через вложенный сериализатор.

### 2. Учебные материалы (`lms`)

* Модели `Course` (Курс), `Lesson` (Урок) и `Subscription` (Подписка) с привязкой к владельцу (`owner`).
* CRUD API для курсов (через `ViewSet`) и уроков (через `Generics`).
* **Валидация контента:** Валидация `video_link` в уроках (разрешены только ссылки на `youtube.com`).
* **Авторизация и подстановка владельца:** Автоматическое заполнение поля `owner` из `request.user` при создании
  объектов.

### 3. Подписки и Уведомления (`Subscription`)

* Реализован эндпоинт установки/снятия подписки на обновления курса (`POST /lms/subscription/`).
* Динамическое поле `is_subscribed` в сериализаторе курса показывает статус подписки текущего пользователя.

### 4. Ролевая модель и права доступа (Permissions)

* **Обычные пользователи:**
    * Видят в списках и могут редактировать/удалять **только свои** курсы и уроки.
* **Группа «Модераторы» (`IsModerator`):**
    * Просмотр и редактирование **всех** курсов и уроков.
    * **Запрещено:** создание новых объектов и удаление существующих.
* **Владельцы (`IsOwner`):**
    * Полный доступ (просмотр, редактирование, удаление) к своим объектам.

### 5. Платежи и интеграция Stripe (`Payment`)

* Модель платежей с привязкой к пользователю, курсу/уроку и способу оплаты (наличные / перевод).
* Сортировка по дате, фильтрация по курсу, уроку и способу оплаты.
* **Онлайн-оплата (Stripe):** При создании платежа автоматически регистрируются продукт и цена в Stripe, а пользователю
  возвращается уникальная ссылка на страницу оплаты (Checkout Session).
* **Проверка статуса:** Реализован отдельный эндпоинт для синхронизации статуса платежа со Stripe.

### 6. Документация API

* Автоматическая генерация спецификации OpenAPI 3 с помощью `drf-spectacular`.
* Эндпоинты снабжены комментариями и ручным описанием параметров.
* Доступны интерактивные панели Swagger UI и ReDoc.

## Основные эндпоинты API

### Документация

- `GET /api/schema/` — Выгрузка схемы OpenAPI в формате YAML/JSON.
- `GET /api/docs/swagger/` — Интерактивная документация Swagger UI.
- `GET /api/docs/redoc/` — Интерактивная документация ReDoc.

### Пользователи

- `POST /users/register/` — Регистрация нового пользователя.
- `POST /users/token/` — Получение JWT-токена.
- `POST /users/token/refresh/` — Обновление JWT-токена.
- `GET, PATCH /users/profile/` — Просмотр и редактирование своего профиля.

### Курсы (ViewSet)

- `GET /lms/courses/` — Список курсов (фильтрация по владельцу для обычных пользователей / полный список для
  модераторов).
- `POST /lms/courses/` — Создание курса (запрещено для модераторов).
- `GET /lms/courses/<id>/` — Детальная информация о курсе (включая флаг `is_subscribed`).
- `PUT, PATCH /lms/courses/<id>/` — Обновление курса (владелец или модератор).
- `DELETE /lms/courses/<id>/` — Удаление курса (только владелец).

### Уроки (Generics)

- `GET /lms/lessons/` — Список уроков.
- `POST /lms/lessons/create/` — Создание урока (с валидацией YouTube-ссылки).
- `GET /lms/lessons/<id>/` — Детальная информация об уроке.
- `PUT, PATCH /lms/lessons/<id>/update/` — Обновление урока.
- `DELETE /lms/lessons/<id>/delete/` — Удаление урока.

### Подписки

- `POST /lms/subscription/` — Переключение (установка/снятие) подписки авторизованного пользователя на курс.

### Платежи

- `GET /users/payments/` — Список платежей (поддерживает сортировку `?ordering=-payment_date` и
  фильтры `?paid_course=`, `?payment_method=`).
- `POST /users/payments/create/` — Создание нового платежа (возвращает ссылку на оплату Stripe).
- `GET /users/payments/<id>/status/` — Проверка статуса оплаты платежа в Stripe.

## Установка и запуск

1. **Клонирование репозитория:**

```bash
git clone git@github.com:ivanitch/skypro-lms.git skypro-lms
cd skypro-lms
```

2. **Настройка окружения:**

```bsah
cp .env.example .env
uv sync
```

3. **Миграции:**

```bash
uv run python manage.py makemigrations
uv run python manage.py migrate
```

4. **Загрузка тестовых данных и фикстуры групп:**

```bash
uv run python manage.py loaddata groups_fixture.json
uv run python manage.py loaddata payments_fixture.json
# или через команду: uv run python manage.py load_payments
```

5. **Создание суперпользователя:**

```bash
uv run python manage.py createsuperuser
```

6. **Запуск сервера**

```bash
uv run python manage.py runserver

# или
./server.sh
```

7. **Тестирование и покрытие кодом**

```bash
uv run python manage.py test

uv run coverage run --source='.' manage.py test
uv run coverage report
```
