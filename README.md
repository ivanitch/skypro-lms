# Skypro LMS - Онлайн образовательная система

Бэкенд-часть образовательной платформы (LMS), разработанная на базе **Django 6** и **Django REST Framework (DRF)**.
Система предоставляет API для управления курсами, уроками, платежами, пользователями и их ролевыми правами доступа.

---

## Стек технологий

* **Python:** 3.12+
* **Фреймворк:** Django 6.0
* **API:** Django REST Framework (DRF)
* **База данных:** PostgreSQL
* **Менеджер пакетов и окружений:** `uv`
* **Фильтрация:** `django-filter`

---

## Функционал

### 1. Управление пользователями и профилями (`users`)

* Кастомная модель `User` унаследована от `AbstractBaseUser`, аутентификация по **Email**.
* Дополнительные поля: `phone`, `city`, `avatar`.
* **Ограничения доступа:** Пользователь может просматривать и редактировать **только свой собственный профиль** (при
  попытке доступа к чужому возвращается `403 Forbidden`).
* Вывод истории платежей пользователя через вложенный сериализатор.

### 2. Учебные материалы (`lms`)

* Модели `Course` (Курс) и `Lesson` (Урок) с привязкой к владельцу (`owner`).
* CRUD API для курсов (через `ViewSet`) и уроков (через `Generics`).
* Вложенные сериализаторы (вывод количества и списка уроков внутри курса).
* **Авторизация и подстановка владельца:** При создании курса/урока поле `owner` заполняется автоматически
  из `request.user`.

### 3. Ролевая модель и права доступа (Permissions)

* **Обычные пользователи:**
    * Видят в списках и могут редактировать/удалять **только свои** курсы и уроки.
* **Группа «Модераторы» (`IsModerator`):**
    * Могут просматривать и редактировать **все** курсы и уроки.
    * **Запрещено:** создавать новые курсы/уроки и удалять существующие.
* **Владельцы (`IsOwner`):**
    * Полный доступ (просмотр, редактирование, удаление) к своим объектам.

### 4. Платежи (`Payment`)

* Модель платежей с привязкой к пользователю, курсу/уроку и способу оплаты (наличные / перевод).
* Сортировка по дате, фильтрация по курсу, уроку и способу оплаты.

## Основные эндпоинты API

### Пользователи

- `POST /users/register/` — Регистрация нового пользователя.
- `GET, PATCH /users/profile/` (или `/users/profile/<id>/`) — Просмотр и редактирование своего профиля (со списком
  платежей).

### Курсы (ViewSet)

- `GET /lms/courses/` — Список курсов (фильтрация по владельцу для пользователей / полный список для модераторов).
- `POST /lms/courses/` — Создание курса (запрещено для модераторов).
- `GET /lms/courses/<id>/` — Детальная информация о курсе.
- `PUT, PATCH /lms/courses/<id>/` — Обновление курса (владелец или модератор).
- `DELETE /lms/courses/<id>/` — Удаление курса (только владелец).

### Уроки (Generics)

- `GET /lms/lessons/` — Список уроков.
- `POST /lms/lessons/create/` — Создание урока.
- `GET /lms/lessons/<id>/` — Детальная информация об уроке.
- `PUT, PATCH /lms/lessons/<id>/update/` — Обновление урока.
- `DELETE /lms/lessons/<id>/delete/` — Удаление урока.

### Платежи

- `GET /users/payments/` — Список платежей (поддерживает сортировку `?ordering=-payment_date` и
  фильтры `?paid_course=`, `?payment_method=`).

## Установка и запуск

1. **Клонирование репозитория:**

```bash
git clone git@github.com:ivanitch/skypro-lms.git skypro-lms
cd skypro-lms
```

2. **Настройка окружения:**

```bsah
cp .env.example .env
uv sync
```

3. **Миграции:**

```bash
uv run python manage.py makemigrations
uv run python manage.py migrate
```

4. **Загрузка тестовых данных и фикстуры групп:**

```bash
uv run python manage.py loaddata groups_fixture.json
uv run python manage.py loaddata payments_fixture.json
# или через команду: uv run python manage.py load_payments
```

5. **Создание суперпользователя:**

```bash
uv run python manage.py createsuperuser
```

6. **Запуск сервера**

```bash
uv run python manage.py runserver

# или
./server.sh
```
