# Skypro LMS - Онлайн образовательная система

Бэкенд-часть образовательной платформы (LMS), разработанная на базе **Django 6** и **Django REST Framework (DRF)**.
Система предоставляет API для управления курсами, уроками, платежами и профилями пользователей.


## Cтек

* **Python:** 3.12+
* **Фреймворк:** Django 6.0
* **API:** Django REST Framework (DRF)
* **База данных:** PostgreSQL
* **Менеджер пакетов и окружений:** `uv`
* **Фильтрация:** django-filter


## Функционал

1. **Приложение `users` (Управление пользователями):**
    * Кастомная модель пользователя унаследована от `AbstractBaseUser`.
    * Авторизация реализована через Email (поле `username` удалено).
    * Добавлены дополнительные поля: `phone`, `city`, `avatar`.
    * Разработан эндпоинт для редактирования профиля пользователя (через `RetrieveUpdateAPIView`).
    * Добавлена модель **Платежи (`Payment`)** со связями:
        * `user` — ссылка на пользователя, совершившего оплату;
        * `payment_date` — дата оплаты;
        * `paid_course` / `paid_lesson` — ссылка на оплаченный курс или урок (соответствующие модели `Course`/`Lesson`);
        * `amount` — сумма оплаты;
        * `payment_method` — способ оплаты (наличные или перевод на счёт).
    * Тестовые данные для платежей загружаются через фикстуру / кастомную management-команду.
    * В профиле пользователя реализован вывод истории платежей — сериализатор профиля расширен вложенным списком платежей пользователя.

2. **Приложение `lms` (Учебные материалы):**
    * Модели `Course` (Курс) и `Lesson` (Урок) со связью "один-ко-многим".
    * CRUD API для сущности "Курс" реализован с использованием `ViewSets`.
    * CRUD API для сущности "Урок" реализован через `Generic` классы.
    * Настроены базовые сериализаторы для корректного отображения и валидации данных.
    * В сериализатор курса добавлено поле подсчёта количества уроков (реализовано через `SerializerMethodField`).
    * В сериализатор курса добавлен вывод списка связанных уроков — единый сериализатор возвращает количество уроков курса и полную информацию по каждому из них.

3. **Фильтрация платежей:**
    * Эндпоинт списка платежей поддерживает:
        * сортировку по дате оплаты (по возрастанию/убыванию);
        * фильтрацию по оплаченному курсу или уроку;
        * фильтрацию по способу оплаты.

## Установка и запуск проекта

Подготовка окружения

Склонируйте репозиторий на локальную машину:

```bash
git clone git@github.com:ivanitch/skypro-lms.git skypro-lms
cd skypro-lms
```

Скопировать файл конфигурации

```bash
cp .env.example .env
```

Для управления зависимостями и виртуальным окружением используется `uv`. Синхронизируйте проект:

```bash
uv sync
```

Миграции

```bash
uv run python manage.py makemigrations
uv run python manage.py migrate
```

Загрузка тестовых данных (платежи)

```bash
uv run python manage.py loaddata payments_fixture.json
```

или через кастомную команду:

```bash
uv run python manage.py load_payments
```

Создать супер-пользователя

```bash
uv run python manage.py createsuperuser
```

Запустите локальный сервер:

```bash
uv run python manage.py runserver
```

## Доступные эндпоинты API

Пользователи:

    GET, PUT, PATCH /users/profile/<id>/ - Просмотр и редактирование профиля (включает историю платежей).

Курсы (ViewSet):

    GET /lms/courses/ - Список курсов (с количеством уроков).

    POST /lms/courses/ - Создание курса.

    GET /lms/courses/<id>/ - Детальная информация о курсе (количество уроков + список привязанных уроков).

    PUT, PATCH /lms/courses/<id>/ - Обновление курса.

    DELETE /lms/courses/<id>/ - Удаление курса.

Уроки (Generics):

    GET /lms/lessons/ - Список уроков.

    POST /lms/lessons/create/ - Создание нового урока.

    GET /lms/lessons/<id>/ - Детальная информация об уроке.

    PUT, PATCH /lms/lessons/<id>/update/ - Обновление урока.

    DELETE /lms/lessons/<id>/delete/ - Удаление урока.

Платежи:

    GET /users/payments/ - Список платежей с поддержкой:
        * ?ordering=payment_date или ?ordering=-payment_date - сортировка по дате оплаты;
        * ?paid_course=<id> - фильтр по оплаченному курсу;
        * ?paid_lesson=<id> - фильтр по оплаченному уроку;
        * ?payment_method=cash|transfer - фильтр по способу оплаты.
